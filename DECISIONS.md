## 2026-09-12 — Escopo do kit vs. ativos existentes

- **Contexto:** O portfólio ao vivo já está publicado em https://lughlammas.github.io/. Existe o template de produto https://github.com/lughlammas/comercial-template.
- **Decisão:** Criar `ai-coordinator-portfolio` como **starter kit / metodologia** (playbooks, papéis, prompts), complementar ao site e ao template — não como substituto de nenhum dos dois.
- **Consequências:**
  - Este repo documenta *como* coordenar agentes; o github.io continua sendo a vitrine.
  - O `comercial-template` **não é modificado** por este trabalho; produtos nascem por clone/template em repos novos.
  - Homepage deste repositório no GitHub aponta para https://lughlammas.github.io/.
- **Status:** Aceito.
